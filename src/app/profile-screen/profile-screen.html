SubMISSION

Jiu-Jitsu Submission Tracking App

Built for Performance Analysis & Habit Tracking

About the Project

  • Tracks jiu-jitsu submissions and training data over time.
  • Provides visual analytics to identify habits and trends.
  • Designed for ease of use with in-line editing and fast data entry.

Core Features

  • User authentication with per-user data isolation.
  • Full CRUD operations on submission history.
  • Real-time data visualization through dynamic pie charts.
  • Dashboard displaying most recent submissions.

Tech Stack

  • Frontend: Angular
  • Backend: Supabase
  • Database: PostgreSQL
  • Authentication: Supabase Auth
